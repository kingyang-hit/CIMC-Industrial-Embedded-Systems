工程文件为嘉立创 EDA 专业版格式（`.epro2`）。【 Gerber / 原理图截图 / 开源广场链接——按实际情况说明】
跟大家分享一些设计过程的阻碍吧，我认为最大的困难是理解主办方的需求，早期还没发布评分细则时，打了一版电源和采样放一起的，主要为了早点开展代码测试。后来，出了评分细则后，要分为三个板子，而且PT100并没有实际用到，只是作为一个背景出现（当然接口还是设计的和PT100一致）。
首先是电源板的需求，需要预留万用表电流测量接口，由于没有夹式的万用表，实际测试时，接法上困扰了一阵，而且接入表后，由于接触阻抗，会对后面的电压输出造成一点点影响。这个电流表测数，会在后面代码的低功耗模式有所使用。然后36V输入的要求，实在是借不到这样的数字电源，随未做测试。另外要测试满载输出，没有电子负载，使用黄铜的功率电阻模拟的满载，建议提前联系，借用仪器。
温度采样板方面，还OK，主要是借鉴了一些大佬开源的三线制采样方案。
精密电阻模拟测试板，主要是买电阻不好买。
